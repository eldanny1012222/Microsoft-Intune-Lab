# Windows Security Baseline Lab

## Overview
Created a Microsoft Intune Windows configuration profile to practice endpoint security management and device configuration.

## Platform
Windows 10 and later

## Assignment
All devices

## Configured Security Settings

### BitLocker
- Require Device Encryption: Enabled
- Configure Recovery Password Rotation: Enabled

### Microsoft Defender
- Cloud Protection: Enabled
- Real-Time Monitoring: Enabled
- Behavior Monitoring: Enabled
- Script Scanning: Enabled
- On Access Protection: Enabled

### Attack Surface Reduction (ASR)
- Block Office applications from creating executable content
- Block credential stealing from the Windows Local Security Authority Subsystem (LSASS)
- Block Office applications from creating child processes

## Skills Demonstrated
- Microsoft Intune administration
- Windows endpoint management
- BitLocker configuration
- Microsoft Defender configuration
- Endpoint security policies
- Security baseline implementation
